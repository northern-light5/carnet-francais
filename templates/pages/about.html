Our mission

Learning French should be accessible to everyone. The practice tools on this site are free, need no account, and keep your progress only in your own browser.

Open source

The whole website is open source under the MIT licence. It is a small static site built with a single Python script and no external services, so anyone can run it — even on a Raspberry Pi.

  • Fix a typo, add vocabulary or suggest a book by opening a pull request.
  • Course, book and contact details live in simple JSON files in content/.
  • Fork it to build a learning site for another language.

Privacy
